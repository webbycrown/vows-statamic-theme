# Vows - Statamic Starter Kit

Vows is a wedding planning starter kit for planners, venues, and celebration studios. It is built for Statamic 5 with a blush-and-gold layout, named packages, a booking calendar, and Control Panel content management.

The kit ships four home variants, package listings, booking, events, shop pages, blog and podcast layouts, and membership content so a planner can publish offerings and take inquiry bookings from one site.

## Collections

Organize your content with built-in collections (handles in parentheses):

- **Pages**: Site structure and hierarchical content.
- **Packages** (`classes`): Wedding packages and service tiers.
- **Events**: Open houses, fairs, and styled shoots.
- **Experiences** (`retreats`): Destination weekends and hosted celebrations.
- **Products**: Favors and shop items.
- **Blogs**: Planning guides and real-wedding stories.
- **Podcast** and **Podcast episode**: Audio series and individual episodes.
- **Teams**: Planners and coordinators.
- **Testimonials**: Couple reviews.
- **FAQs**: Planning and booking questions.
- **Comments**: Blog and package comments.

## Installation

Follow the [Starter Kit installation instructions](https://statamic.dev/starter-kits/installing-a-starter-kit) to get started with Vows.
Make sure you're running **Statamic 5.x** for compatibility.

### Installing into an existing site

```bash
php please starter-kit:install webbycrown/vows-statamic-theme
```

### Installing via the Statamic CLI Tool

If you have the [Statamic CLI Tool](https://github.com/statamic/cli) installed, create a new Statamic installation with Vows in one command:

```bash
statamic new my-site webbycrown/vows-statamic-theme
```
